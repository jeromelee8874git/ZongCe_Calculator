# ZongCe Calculator v2.0.0

首个面向公开使用的正式在线版本。

## 适用范围

广东工业大学 2025～2026 学年综合测评。

本版本面向广东工业大学 2025～2026 学年综合测评。后续学年相关规则如发生调整，请使用对应更新版本，并以学校、学院当年度正式文件为准。

## 使用方式

- 推荐：[GitHub Pages 在线版](https://jeromelee8874git.github.io/ZongCe_Calculator/)
- 本地：下载后直接打开 `index.html`

填写五项成绩或修改权重后，页面会实时更新综合测评总分。权重合计不是 100% 时，页面会显示异常提醒，但仍按当前输入权重计算。

## 隐私说明

所有成绩计算均在浏览器本地完成，不会上传或保存用户成绩。本版本不包含统计分析、持久化存储或第三方网络请求。

## 免责声明

本工具为个人开发的非官方综合测评辅助计算器。本版本面向广东工业大学 2025～2026 学年综合测评，仅用于成绩估算与参考。具体计算规则、权重、适用条件及最终综合测评结果，请以广东工业大学及所在学院当年度正式文件和官方认定结果为准。
