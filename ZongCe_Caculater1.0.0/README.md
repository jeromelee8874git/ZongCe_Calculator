# 学生综合测评成绩计算器

一个可在 Windows 本地直接使用的轻量网页应用，不需要安装依赖，也不会上传或保存成绩。

## 启动

- 双击 `启动计算器.bat`；或
- 直接双击 `index.html`。

页面会使用默认浏览器打开。填写 D、X、C、S、W 中的任意一项后，总分 P 会立即更新。

## 计算公式

```text
P = D × 8% + X × 65% + C × 15% + S × 7% + W × 5%
```

体质测试评价 T 仅作记录，不计入 P。

## 项目结构

- `index.html`：页面结构与中文内容
- `styles.css`：响应式界面样式
- `js/calculator.js`：权重、输入校验和计算逻辑
- `js/app.js`：实时输入监听、结果显示和清空交互
- `tests/`：计算与界面交互自动化测试

## 运行测试

如果电脑已安装 Node.js，在项目目录执行：

```powershell
npm test
```
