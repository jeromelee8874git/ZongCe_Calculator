# ZongCe_Calculator — 学生综合测评成绩计算器

`ZongCe_Calculator` 是一个轻量、开源的学生综合测评成绩辅助计算器。项目名称长期保持不变；学校、学年与规则适用范围由各版本单独记录。

## 当前版本

**ZongCe Calculator v2.0.0**

- 适用范围：广东工业大学 2025～2026 学年综合测评
- 状态：当前推荐公开使用版本
- 使用方式：优先推荐 [GitHub Pages 在线版](https://jeromelee8874git.github.io/ZongCe_Calculator/)

v2.0.0 是首个面向公开使用的正式在线版本。无需安装依赖，可在电脑或手机浏览器中直接使用。

## 快速使用

在线版发布目录为 [`docs/`](./docs/)。也可以下载仓库后直接打开 `docs/index.html`。

填写 D、X、C、S、W 中的任意成绩，或修改公式区域中的权重后，总分 P 会立即更新。默认公式为：

```text
P = D × 8% + X × 65% + C × 15% + S × 7% + W × 5%
```

权重均可修改。权重合计不是 100% 时，页面会继续按当前输入计算，同时显示醒目提醒；请根据学校及所在学院当年度正式文件核对。

## 隐私与安全

- 所有成绩与权重计算均在当前浏览器页面本地完成。
- v2.0.0 不上传、保存或持久化用户输入，也不包含统计分析或第三方网络请求。
- 页面不会要求登录。请勿在任何非官方页面输入账号、密码、身份证号等敏感信息。
- 使用公开电脑后建议点击“清空全部”并关闭页面。
