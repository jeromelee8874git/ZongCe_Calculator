# 学生综合测评成绩计算器

这是一个可在 Windows 本地直接运行的综合测评成绩计算器项目。仓库完整保留了两个相互独立的版本：

- [`ZongCe_Caculater1.0.0/`](./ZongCe_Caculater1.0.0/)：基础版，使用固定的五项权重实时计算综合测评总分。
- [`ZongCe_Caculater1.2.0/`](./ZongCe_Caculater1.2.0/)：支持自定义五项权重，并实时显示当前权重合计。

## 运行方法

进入要使用的版本目录，然后选择以下任一方式：

- 双击 `启动计算器.bat`；或
- 直接双击 `index.html`。

应用会在默认浏览器中打开，不需要安装依赖。两个版本不会上传或保存填写的成绩。

## 运行测试

如果电脑已安装 Node.js，请进入对应版本目录并执行：

```powershell
npm test
```

各版本的功能、计算规则和文件结构详见其目录内的 `README.md`。
