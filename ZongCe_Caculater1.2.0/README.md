# 学生综合测评成绩计算器

一个可在 Windows 本地直接使用的轻量网页应用，不需要安装依赖，也不会上传或保存成绩。1.2.0 版支持直接修改五项权重。

## 启动

- 双击 `启动计算器.bat`；或
- 直接双击 `index.html`。

页面会使用默认浏览器打开。填写 D、X、C、S、W 中的任意一项，或修改公式区域中的任意权重后，总分 P 都会立即更新。

## 计算公式与权重

```text
P = D × 8% + X × 65% + C × 15% + S × 7% + W × 5%
```

以上是页面初始默认值。五个权重都可在公式区域修改，单项可填写 0～100 之间的整数或小数；权重合计不强制为 100%，页面会按当前输入值直接计算并实时显示合计。点击“清空全部”会同时恢复上述默认权重。

体质测试评价 T 仅作记录，不计入 P。

## 项目结构

- `index.html`：页面结构与中文内容
- `styles.css`：响应式界面样式
- `js/calculator.js`：默认权重、自定义权重校验和计算逻辑
- `js/app.js`：成绩及权重的实时输入监听、结果显示和清空交互
- `tests/`：计算与界面交互自动化测试

## 运行测试

如果电脑已安装 Node.js，在项目目录执行：

```powershell
npm test
```
